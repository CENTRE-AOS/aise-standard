# Security Policy

> 版本：v1.0
> 状态：Frozen
> 适用范围：所有项目（Repository Generic）

## 1. 总则

本策略定义安全操作规则，防止数据丢失、代码污染和权限泄露。

## 2. 预操作检查

| 规则编号 | 规则 |
|---------|------|
| S1 | Git 操作前先 `git status --short` + `git diff HEAD` 检查变更 |
| S2 | 覆盖 `.md` 文件前创建 `.bak` 备份 |
| S3 | 写入后校验非空 + 含预期标识 |
| S4 | 任何失败按 C3 Recovery Protocol 回滚 |
| S5 | 仅维护 `CHANGELOG.md`、`PROJECT_BLUEPRINT.md`、`.project/` 及已跟踪文件 |
| S6 | 不允许修改 `.gitignore` 增加敏感目录但保留已存在 |
| S7 | 禁止在代码、配置、提示词中存放 PAT、密钥、密码 |

## 3. 编辑安全

| 规则 | 内容 |
|------|------|
| E1 | 编辑前 `git diff` 确认改动范围 |
| E2 | 每次只改最小必要行 |
| E3 | 禁止批量删除跨行代码块 |
| E4 | `old_str` 必须含完整缩进精确匹配 |
| E5 | 超过 5 行须分批执行 |
| E6 | 编辑后 `git diff` 校验，确认无函数体缺失或误删 |
| E7 | 异常回退至 C3 Recovery Protocol |

## 4. 执行安全

| 规则 | 内容 |
|------|------|
| R1 | 每步代码修改后须测试确认 |
| R2 | 测试失败立即停止，绝不继续 |
| R3 | 不执行未经用户确认的破坏性命令 |
| R4 | 不执行 `rm -rf /` 等破坏性操作 |
| R5 | 所有环境修改必须告知用户 |

## 5. 权限与资产

| 规则 | 内容 |
|------|------|
| A1 | AI 不拥有用户资产 |
| A2 | AI 不得自动创建 GitHub 仓库（需要用户权限） |
| A3 | AI 不得自动配置 git remote |
| A4 | AI 不得永久设置 HTTP_PROXY/HTTPS_PROXY |
| A5 | 必须由用户显式同意后才能推送代码 |

## 6. 代理策略

- 代理只能在当前会话临时启用
- 会话结束后必须移除
- 用户环境变量中 HTTP_PROXY/HTTPS_PROXY 必须为空
- 禁止永久写入环境变量

## 7. 变更控制

进入 Frozen 后：

- 允许新增安全规则。
- 禁止放宽现有规则。
